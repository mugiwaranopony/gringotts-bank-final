About Gringotts Bank

Gringotts Bank is a learning project built with the Django web framework.

It demonstrates the core building blocks of every Django project:

  • Models — accounts and transactions stored in SQLite
  • Views — the logic for deposits, withdrawals, and transfers
  • Templates — the pages you are looking at right now
  • URL dispatcher — connecting web addresses to views
  • Forms — validating user input safely
  • Authentication — sign up, log in, log out

⚠️ Please do not deposit real money. We checked — it does not work.
